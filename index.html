This experiment does not implement secrecy coding. Repetition coding helps both receivers recover missing bits. It provides reliability, not secrecy; Eve can use the same decoder as Bob. The secrecy capacity below is a theoretical limit achievable with suitable coding, not a security guarantee for this simulation.

Message format

Text uses UTF-8, 8 bits per byte. Limit: 256 bytes / 2,048 bits. Binary may contain spaces or line breaks.

One surviving copy recovers a bit. More copies cost more channel uses and help Eve too.
